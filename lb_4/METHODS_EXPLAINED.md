# Как работают методы и почему получились такие результаты

В лабораторной работе решаются две разные задачи. В задаче Коши известны значение функции и её производная в начале отрезка. Нужно постепенно построить решение до конца отрезка. В краевой задаче условия заданы на разных концах: известна производная слева и значение функции справа. Решение должно удовлетворять обоим условиям.

Точное решение в обоих заданиях известно из условия. Программы строят приближённое решение самостоятельно, а затем сравнивают его с точным, чтобы узнать фактическую ошибку.

## Метод Эйлера

Метод Эйлера смотрит на текущее состояние и предполагает, что до следующего узла направление изменения останется таким же. По этому направлению он делает шаг и повторяет процесс.

Это похоже на движение по извилистой дороге, когда направление выбирают только в начале каждого шага. Чем длиннее шаг, тем сильнее можно отклониться от дороги, потому что её поворот внутри шага не учитывается.

В программе одновременно изменяются значение функции и её производная. Для вычисления обоих новых значений используются данные из начала шага.

Эйлер прост и требует мало вычислений, но ошибки отдельных шагов накапливаются. В нашем примере при шаге 0,1 максимальная ошибка составила примерно **0,0172**. При достаточно малом шаге его уменьшение вдвое обычно уменьшает ошибку примерно в два раза.

## Метод Рунге — Кутты четвёртого порядка

Этот метод тоже движется от начала отрезка к концу, но перед каждым шагом несколько раз проверяет, как меняется направление решения: в начале, в промежуточных состояниях и около конца шага. Затем объединяет эти сведения и выбирает более точное новое значение.

Благодаря промежуточным проверкам метод лучше учитывает изгиб решения внутри шага. За один шаг он выполняет больше вычислений, чем Эйлер, зато при одинаковой сетке обычно даёт существенно меньшую ошибку.

В нашем примере максимальная ошибка получилась около **0,00000987** — примерно в 1700 раз меньше, чем у Эйлера. При достаточно малом шаге уменьшение шага вдвое обычно уменьшает ошибку примерно в 16 раз.

## Метод Адамса четвёртого порядка

Метод Адамса использует историю движения: сведения о скорости изменения решения в нескольких предыдущих узлах. На их основе он предсказывает следующее значение.

В отличие от Рунге — Кутты, ему не нужно несколько раз проверять промежуточные состояния внутри каждого шага. Поэтому после запуска он требует меньше новых вычислений правой части уравнения. Но начать работу только с одной начальной точки он не может: сначала нужно получить несколько точек другим способом. В нашей реализации первые три шага выполняются методом Рунге — Кутты.

При шаге 0,1 максимальная ошибка Адамса составила примерно **0,00109**. Это лучше Эйлера, но заметно хуже Рунге — Кутты, хотя оба последних метода имеют четвёртый порядок.

Одинаковый порядок не означает одинаковую ошибку. Он описывает, как быстро ошибка уменьшается при измельчении сетки. На её величину также влияют само уравнение, шаг, способ запуска и особенности метода. Здесь прогноз по предыдущим точкам при шаге 0,1 оказался менее точным, чем промежуточные проверки Рунге — Кутты. При уменьшении шага сходимость Адамса приближается к ожидаемому четвёртому порядку.

## Метод стрельбы

В краевой задаче нам известна начальная производная, но неизвестно начальное значение функции. Метод стрельбы пробует некоторое начальное значение и решает задачу до правого конца отрезка. Затем проверяет, насколько полученный результат отличается от требуемого граничного значения.

По результатам проб начальное значение уточняется. Процесс напоминает пристрелку: пробный выстрел показывает отклонение от цели, после чего корректируется следующий.

В программе начальное значение подбирается методом секущих: две предыдущие попытки позволяют оценить, какое значение стоит попробовать дальше. Каждая попытка вычисляется методом Рунге — Кутты четвёртого порядка. Для данного линейного уравнения зависимость результата от подбираемого значения проста, поэтому подбор проходит быстро.

Максимальная ошибка при шаге 0,1 составила примерно **0,00000452**. Правая граница выполняется с очень высокой точностью, поскольку именно попадание в неё контролируется при подборе. Но это не делает всё решение точным: внутри отрезка остаётся ошибка численного интегрирования.

## Конечно-разностный метод

Этот метод не строит решение последовательными шагами от известного начального состояния. Вместо этого он рассматривает значения функции сразу во всех узлах сетки как неизвестные.

Производные приближённо выражаются через соседние значения функции. Вместе с граничными условиями это даёт систему линейных уравнений. Её решение сразу определяет значения функции на всём отрезке.

В нашей реализации каждое внутреннее уравнение связывает только три соседних узла. Это позволяет быстро решить систему методом прогонки: сначала последовательно преобразовать уравнения, затем обратным проходом найти неизвестные значения.

Условие на производную слева также приближённое. Оно реализовано со вторым порядком точности, чтобы не ухудшать порядок всей схемы.

Максимальная ошибка при шаге 0,1 составила примерно **0,00362**. При достаточно малом шаге его уменьшение вдвое уменьшает ошибку примерно в четыре раза. В этом примере метод оказался менее точным, чем стрельба с Рунге — Куттой четвёртого порядка.

## Как понимать сравнение результатов

При шаге 0,1 получены следующие максимальные ошибки по узлам основной сетки:

| Задача | Метод | Максимальная ошибка |
|---|---|---:|
| Коши | Эйлер | 0,0172 |
| Коши | Рунге — Кутта | 0,00000987 |
| Коши | Адамс | 0,00109 |
| Краевая | Стрельба | 0,00000452 |
| Краевая | Конечные разности | 0,00362 |

Сравнивать методы по точности нужно в рамках одной задачи. Например, меньшая ошибка стрельбы по сравнению с Рунге — Куттой из первой задачи не означает, что стрельба вообще точнее: здесь решаются разные уравнения с разными условиями. Более того, сама стрельба использует Рунге — Кутту.

Результаты показывают, что дополнительные сведения об изменении решения помогают повысить точность. Эйлер учитывает только начало шага, Рунге — Кутта исследует промежуточные состояния, Адамс использует предыдущие точки. Конечно-разностный метод учитывает связи между узлами на всём отрезке, но точность этих связей в данной реализации имеет второй порядок.

## Зачем считать с двумя шагами

Кроме сравнения с точным решением, в работе используется оценка Рунге — Ромберга. Для этого одна и та же задача решается дважды: с выбранным шагом и с шагом вдвое меньше. Затем сравниваются значения в совпадающих узлах.

Если при уменьшении шага результаты меняются мало, это помогает оценить оставшуюся ошибку. При оценке учитывается порядок метода: от методов разных порядков ожидается разная скорость улучшения результата.

В программе эта оценка относится к решению на более мелкой сетке. Это приближённая оценка, а не гарантированная граница ошибки. На крупном шаге она может заметно отличаться от фактической ошибки, особенно у Адамса, где на результат влияет ещё и запуск другим методом.

Проверка на более мелких сетках подтвердила ожидаемое поведение: ошибка Эйлера уменьшается примерно в два раза при делении шага пополам, конечных разностей — в четыре, а методов четвёртого порядка — примерно в 16 раз.
