# Лабораторная работа 2.2

Решить систему при a = 3:

```text
F₁(x₁,x₂) = 3x₁² − x₁ + x₂² − 1 = 0,
F₂(x₁,x₂) = x₂ − tan(x₁) = 0.
```

## Запуск

```bash
python3 method_2.py
# Или:
python3 method_2.py --eps 1e-8
```

Нужен только Python 3. Файл `method_1.py` должен находиться рядом: из него используется функция построения SVG. Точность вводится с клавиатуры или через `--eps`; допускаются конечные значения не меньше 1e-14. Результаты сохраняются в `results_2/`: `system.svg` — графики уравнений, `errors.svg` — погрешность от номера итерации, `iteration.csv` и `newton.csv` — полные таблицы.

## Графический выбор приближения

Строим положительную ветвь первого уравнения x₂ = √(1 + x₁ − 3x₁²) и кривую x₂ = tan(x₁). Их пересечение находится около (0.61, 0.70). Выбираем **x⁽⁰⁾ = (0.6, 0.7)** и область D = [0.58, 0.65] × [0.65, 0.75].

Положительное решение единственное. Первое уравнение ограничивает x₁ интервалом 0 < x₁ < (1 + √13)/6 ≈ 0.7676 < π/2. После исключения x₂ получаем h(x₁) = 3x₁² − x₁ + tan²(x₁) − 1. На этом интервале h″(x₁) = 6 + 2sec⁴(x₁) + 4tan²(x₁)sec²(x₁) > 0. Производная начинается с h′(0) = −1 и строго возрастает, так что h сначала убывает от −1, затем возрастает и пересекает нуль только один раз.

## Простая итерация

Используем положительный корень квадратного уравнения по x₁ и последовательное обновление переменных:

```text
g(y) = (1 + √(13 − 12y²))/6,
x₁⁽ᵏ⁺¹⁾ = g(x₂⁽ᵏ⁾),
x₂⁽ᵏ⁺¹⁾ = tan(x₁⁽ᵏ⁺¹⁾).
```

Это векторная итерация x⁽ᵏ⁺¹⁾ = Φ(x⁽ᵏ⁾), где Φ(x₁,x₂) = (g(x₂), tan(g(x₂))). Новое значение x₁ сразу используется для вычисления x₂.

На D: g(x₂) ∈ [0.58333, 0.63596], а tan(g(x₂)) приблизительно лежит в [0.660, 0.738], поэтому Φ(D) ⊂ D.

Используем норму ||x||∞ = max(|x₁|, |x₂|). Матрица производных Φ имеет нулевой первый столбец; её второй столбец равен (g′(x₂), sec²(g(x₂))g′(x₂)), где g′(y) = −2y/√(13 − 12y²). Получаем гарантированную верхнюю границу нормы:

```text
||Φ′||∞ ≤ (2·0.75 / √(13 − 12·0.75²)) · sec²(g(0.65))
         = q ≈ 0.92709772 < 1.
```

Следовательно, Φ — сжатие, и метод сходится. Условие остановки:

```text
q/(1−q) · ||x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾||∞ ≤ eps.
```

## Метод Ньютона

На каждом шаге решаем систему J(x⁽ᵏ⁾)δ = −F(x⁽ᵏ⁾), затем x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + δ. Матрица Якоби:

```text
J(x) = [ 6x₁ − 1       2x₂ ]
       [ −sec²(x₁)      1  ].
```

Линейная система 2×2 решается явными формулами через определитель; сторонняя библиотека не требуется. В D определитель (6x₁ − 1) + 2x₂sec²(x₁) положителен.

Для проверки точности Ньютона применяем оценку, следующую из свойства сжатия Φ и неравенства треугольника:

```text
||x − x*||∞ ≤ ||x − Φ(x)||∞ / (1 − q).
```

Останавливаемся, когда правая часть не превосходит eps. Программа проверяет, что каждое приближение остаётся в D, где эта оценка обоснована. Это условие контролирует погрешность решения, а не только величину шага. Оценки теоретически верны в точной арифметике; у предела точности float существенны ошибки округления.

## Результат и анализ погрешности

```text
x₁* ≈ 0.61109781647175133557,
x₂* ≈ 0.70055420388584101460.
```

Независимый эталон получается бисекцией для h(x₁), с десятичной арифметикой Decimal (70 значащих цифр, 200 шагов). Тангенс для эталона вычисляется как отношение рядов Тейлора синуса и косинуса. Фактическая погрешность в таблицах — максимальная абсолютная ошибка двух компонент относительно эталона. Невязка ||F||∞ приводится отдельно.

При eps = 1e-8:

| Метод | Число итераций | Фактическая погрешность ||x − x*||∞ |
| --- | ---: | ---: |
| Простая итерация | 59 | 3.057·10⁻¹⁰ |
| Ньютон | 3 | 2.070·10⁻¹⁶ |

Простая итерация сходится линейно. Вблизи решения отношение последовательных ошибок стремится примерно к 0.78330. Знак отклонения меняется, поэтому приближения колеблются около решения; график абсолютной ошибки в логарифмической шкале близок к прямой. Теоретическая граница q консервативна: фактическая ошибка становится меньше eps раньше, чем оценка для остановки.

Ньютон сходится квадратично вблизи решения. Для выбранного начального приближения фактическая ошибка после шагов 0, 1, 2 и 3 составляет соответственно 1.110·10⁻², 1.171·10⁻⁴, 1.333·10⁻⁸ и 2.070·10⁻¹⁶. На третьем шаге достигнут уровень машинного округления, поэтому дальнейшее квадратичное уменьшение наблюдать нельзя.

Проверены eps = 1e-3, 1e-8, 1e-12, 1e-14: оба метода достигают заданной абсолютной точности и остаются в D.
