# Лабораторная работа 2.1

Решить уравнение **f(x) = x⁶ − 5x − 2 = 0** методами простой итерации и Ньютона, задавая точность вычислений.

## Запуск

Требуется Python 3, сторонние библиотеки не нужны.

```bash
python3 main.py
# Или задать точность в командной строке:
python3 main.py --eps 1e-8
```

Программа выводит корни, количество итераций и таблицы погрешностей. В `results/` сохраняются таблицы CSV, график функции `function.svg` и график погрешностей `errors.svg`. SVG можно открыть в браузере. Допустимая точность: конечное число eps ≥ 1e-14; ограничение связано с арифметикой float.

## Выбор начального приближения

По графику функции положительный корень расположен между 1.4 и 1.5:

- f(1.4) = −1.470464;
- f(1.5) = 1.890625.

Выбираем x₀ = 1.5 для обоих методов. На этом интервале f′(x) = 6x⁵ − 5 > 0 и f″(x) = 30x⁴ > 0. Для Ньютона выполнено f(x₀)f″(x₀) > 0, поэтому приближения убывают к корню и остаются в интервале.

Положительный корень единственный: на положительной полуоси производная меняет знак один раз, в c = (5/6)^(1/5). До c функция убывает от f(0) = −2, а после c строго возрастает до бесконечности.

## Простая итерация

Преобразуем уравнение:

```text
x = φ(x) = (5x + 2)^(1/6)
xₖ₊₁ = φ(xₖ)
φ′(x) = 5 / (6(5x + 2)^(5/6))
```

Функция φ возрастает и переводит [1.4, 1.5] в себя: φ(1.4) ≈ 1.44225, φ(1.5) ≈ 1.45530. Максимум производной достигается в левой границе: q = φ′(1.4) ≈ 0.133542 < 1. Поэтому итерации сходятся. Апостериорная оценка и условие остановки:

```text
|xₖ − x*| ≤ q/(1 − q) · |xₖ − xₖ₋₁| ≤ eps.
```

## Метод Ньютона

```text
xₖ₊₁ = xₖ − (xₖ⁶ − 5xₖ − 2)/(6xₖ⁵ − 5).
```

Для остановки используется оценка из теоремы Лагранжа:

```text
|xₖ − x*| ≤ |f(xₖ)|/m ≤ eps,
m = min f′(x) на [1.4, 1.5] = f′(1.4) = 27.26944.
```

Это оценки в точной арифметике; при очень малых eps проявляются ошибки округления float.

## Анализ погрешности

Независимый эталон вычисляется бисекцией с 70 значащими десятичными цифрами (220 шагов). Фактическая абсолютная погрешность каждого приближения определяется относительно этого эталона. На графике погрешности используется логарифмическая шкала.

Положительный корень: **x* ≈ 1.44867805636486663414**.

При eps = 1e-8 и x₀ = 1.5:

| Метод | Итерации | Результат | Абсолютная погрешность |
| --- | ---: | ---: | ---: |
| Простая итерация | 8 | 1.448678060652963 | 4.288·10⁻⁹ |
| Ньютон | 3 | 1.448678060143001 | 3.778·10⁻⁹ |

Простая итерация сходится линейно: вблизи корня eₖ₊₁/eₖ ≈ |φ′(x*)| ≈ 0.13060. На логарифмическом графике это примерно прямая линия. Метод Ньютона сходится квадратично: eₖ₊₁ ≈ |f″(x*)/(2f′(x*))|eₖ², поэтому погрешность уменьшается значительно быстрее. Например, для Ньютона ошибки составляют примерно 5.13·10⁻², 4.71·10⁻³, 4.36·10⁻⁵, 3.78·10⁻⁹. При достижении машинной точности эта закономерность нарушается из-за округления.
