## 4.1. Задача Коши

Условие:

```text
x²y'' + (x+1)y' − y = 0,
y(1) = 2+e, y'(1) = 1, x ∈ [1,2].
Точное решение: y(x) = x+1+x·exp(1/x).
```

Замена z=y' даёт систему y'=z, z'=(y−(x+1)z)/x².
Обе компоненты вычисляются совместно:

- явный Эйлер: y[i+1]=y[i]+h·z[i], z[i+1]=z[i]+h·f[i], порядок 1;
- классический четырёхстадийный Рунге — Кутта, порядок 4;
- явный Адамс — Башфорт четвёртого порядка: для каждой компоненты
  u[i+1]=u[i]+h·(55F[i]−59F[i−1]+37F[i−2]−9F[i−3])/24.
  Первые три шага вычисляются методом Рунге — Кутты.

## 4.2. Краевая задача

```text
(x²+1)y'' − 2y = 0,
y'(0)=2, y(1)=3+π/2, x ∈ [0,1].
Точное решение: y(x)=x²+x+1+(x²+1)·arctan(x).
```

В методе стрельбы неизвестное начальное значение y(0)=η подбирается
методом секущих по невязке y(1;η)−(3+π/2). Каждая пристрелка решается RK4.
Допуск невязки — 10⁻¹², ограничение — 20 итераций.
Точное решение не используется при подборе η.

В конечно-разностном методе внутренние уравнения имеют вид

```text
y[i−1] − (2+2h²/(1+x[i]²))y[i] + y[i+1] = 0.
```

Для условия y'(0)=2 вводится фиктивный узел:
y[−1]=y[1]−4h. После подстановки в разностное ОДУ при x=0 получается
(1+h²)y[0]−y[1]=−2h. Это аппроксимация граничного условия второго порядка:
из разложения Тейлора и y''(0)=2y(0) следует
(y[1]−y[0])/h−h·y[0]=y'(0)+O(h²).
Справа задаётся y[N]=3+π/2. Трёхдиагональная система решается прогонкой.

## Погрешности и результаты

Каждое решение вычисляется на сетках h и h/2. Сравнение проводится
в общих узлах x[i] и x_fine[2i]. Формула Рунге — Ромберга:

```text
δ = (y_h/2 − y_h)/(2^p − 1),
оценка ошибки решения на сетке h/2: |δ|,
уточнённое решение: y_R = y_h/2 + δ.
```

Это асимптотическая оценка, а не гарантированная верхняя граница ошибки.
Для оценки ошибки грубой сетки соответствующая величина равна 2^p·|δ|.
На сравнительно крупном шаге, особенно для Адамса со стартом RK4,
оценка может заметно отличаться от фактической ошибки.

Таблицы содержат решение на шаге h, точное значение, абсолютные ошибки
на h и h/2 и оценку Рунге — Ромберга для h/2.
В CSV дополнительно сохранены y_h/2 и уточнённое решение y_R.
Максимумы для h/2 вычисляются по общим узлам с грубой сеткой.

При h=0.1 максимальная абсолютная ошибка на основной сетке:

| Метод | max ошибки |
|---|---:|
| Эйлер | 1.719236e-2 |
| Рунге — Кутта | 9.868449e-6 |
| Адамс | 1.087491e-3 |
| Стрельба | 4.517786e-6 |
| Конечные разности | 3.621109e-3 |

Готовые таблицы находятся в `results/` и воспроизводятся командой
`python main.py --h 0.1 --output results`.

Проверена сходимость на шагах 0.025, 0.0125, 0.00625.
Наблюдаемые порядки на последних двух сетках: Эйлер — 1.003,
RK4 — 4.010, Адамс — 3.878, стрельба — 3.991,
конечные разности — 2.000. Проверены граничные условия и отклонение
некорректных шагов (нулевой, отрицательный, NaN и не делящий отрезок).
